# Trash Collector Game

This repository contains a small retro-style simulation game where a simple AI collects trash and throws it into a hole. Each piece of trash earns currency which can later be used for upgrades.

## Running the Game

1. Install dependencies:
   ```bash
   pip install pygame
   ```
2. Run the game:
   ```bash
   python -m src.main
   ```

The code is organized into modules under `src/` so new features can be added easily without modifying the entrypoint.
